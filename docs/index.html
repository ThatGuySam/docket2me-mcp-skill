Codex is best for the live technical demo or attendees comfortable pasting one command into a terminal. OAuth still happens in the browser.

Copy this Codex setup command

It adds the remote MCP server, then starts Docket2Me sign-in.

codex mcp add docket2me --url https://docket2me.ai/mcp && codex mcp login docket2me
